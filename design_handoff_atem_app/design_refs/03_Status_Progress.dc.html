B1 · FORTSCHRITT — EINE FAMILIE, ZWEI MODI
AtemProgress: Form ist frei, Modus ist bindend
Es ist EINE Familie (Arc, Ring, Balken teilen Track-Farbe, Kappenlogik, Semantics), aber mit zwei Modi, die sich in Richtung und Bewegung unterscheiden:
MODUS ANTEIL — „wie viel von X"
Wächst von 0 auf Wert. Wertänderung animiert 600 ms ease-out-cubic (Kurzform des Score-Count-ups — gleiche Kurve, damit es nach Messwert aussieht, nicht nach Ladebalken). Arc-Gauge, Protein-Ring, Phasen-Balken.
MODUS ABLAUF — „wie viel Zeit bleibt"
Schrumpft von 100 % auf 0, streng linear im Sekundentakt (Vorgabe Modul 1, bleibt bei reduzierter Bewegung). Nie ease-Kurven — ein easender Countdown lügt über die Restzeit. Pausen-Fortschritt.
Glow-Budget: genau EINE geblurrte Kopie (Blur ≤ 8 dp, Alpha ≤ 0,35) UNTER dem Wertstrich, nie über ihm; der Track bleibt glowfrei. Ein zweiter Glow oder Glow auf dem Track senkt den Kantenkontrast des Füllstands unter Ablesbarkeit — dann lieber gar keiner.
Randzustände: 0 %, 100 %, unbestimmt
Runde Kappen zeigen bei 0 % einen Punkt, der wie 2 % aussieht — deshalb Kappenwechsel unterhalb der Kappenbreite:
0 % — TRACK PUR
Kein Wertstrich, kein Glow. Unter 3 % wird der Strich ohne Kappen (butt) gezeichnet, ab 3 % rund.
100 % — GESCHLOSSEN + HAKEN
Voll = Lime + Haken ersetzt die Zahl (Form, nicht nur Farbe). Verlauf weicht der Erfolgs-Volltonfarbe.
UNBESTIMMT — SEGMENT-ATMEN
Kein rotierender Kreisel, kein Akzent: ein graues Segment wandert langsam (2,4 s) über den Track. Zahl zeigt „—". Reduzierte Bewegung: statisch gepunkteter Track.
Countdown-Ende (bisher nur Haptik + Ton): Der Track der Rest-Leiste blitzt zweimal limefarben auf (endFlash, 2 × 400 ms, ease-out) und die Leiste kollabiert erst danach — das visuelle Signal ist damit auch ohne Ton/Vibration vorhanden. Reduzierte Bewegung: ein einzelner Farbwechsel des Tracks auf Lime für 800 ms, kein Blitzen.
